## 2. 实现过程

### 2.1 枚举与二面体分类（`block_classes.py`）

对 `{5,2}`（7-圈）、`{2⁴}`、`{2,2,4}`、`{4,4}`、`{6,2}`（8-圈）以及
`{2,2,2}`（6-圈，对照组）：枚举全部块分拆，按 `D_k`（阶 2k）求轨道，
报告分拆总数、轨道数、轨道大小谱，并与 r129 §4 的记录逐项比对。

**一次自伤，值得留档。**
枚举器初版对**大小不同**的块也套用了"最小元固定在首块"的去重技巧：

```python
head = rem[0]
for comb in combinations(rem[1:], s-1):    # 错：强制 head 进当前块
```

这只在**等大小**块之间是合法的商（等大小块可互换）。结果漏掉了一部分：
`{5,2}` 21→15、`{2,2,4}` 210→105、`{6,2}` 28→21。

抓住它的**不是**与 r129 的比对（轨道数 3/22/4 竟然还都"对"），而是一个廉价不变量：

> 报告里出现了 `D₇`（阶 14）下 **size 5** 的轨道 —— **轨道大小必须整除群阶**，
> 5 ∤ 14，不可能。

**修**：只有当"剩余尺寸表里还有同样大小的块"时才强制，否则枚举全部 s-子集：

```python
force = bool(rest) and rest[0] == s
cands = ([(rem[0],)+c for c in combinations(rem[1:], s-1)] if force
         else list(combinations(rem, s)))
```

并额外用闭式独立核对总数：`C(7,2)`、`7!!`、`C(8,4)·3!!`、`C(8,4)/2`、`C(8,2)`。

**教训入册**：轨道大小整除群阶，这条检查已固化进报告输出。

### 2.2 `{2⁴}` 的精确积分（`p24_exact.py`）

`{2⁴}` 是八边形**八条边**的配对（4 个自由变量），与 `{2,2,2}` 完全同构，
只是维数从 3 升到 4：

```
val = ∫ (1 − spread(walk))₊ · |v₁||v₂||v₃||v₄| dv
```

走位构造复用 `phase0/chord_classes.walk(matching, n=8)`；积分直接调用
Phase 0 的方法 B（`walk_polytope.integral`），它本来就是**任意维**写的。

先做单类计时探针（第一个轨道代表），确认 d=4 可行（9.6 s，16 个符号轨道中
一半由 `v→−v` 对称省掉），再用 8 进程并行跑 17 个轨道代表。

**一个小 bug**：`verbose` 分支里引用了已被我删掉的 `tri` 变量（改锥剖分时留下的
残迹），只在 `-v` 下触发；改为 `len(simplices)`。

### 3.4 两点必须记入册

**(a) r129 阶梯的带宽偏乐观约 3 倍。**
报的是 `±3×10⁻⁷`，实际偏差 `8.1×10⁻⁷`。h⁴ 外推的不确定度被低估。
**建议**：F-P24 的判据从 `3e-7` 放宽到 `3e-6`，或改用两档独立外推取包络。

**(b) 分母 3780 = 2²·3³·5·7 不整除 2520**（差在 3³ vs 3²）。
这**精确解释**了 r129"小分母（≤2520）重构无命中"：候选集里根本没有真值。
纲领 Outlook (e) 的经验规律"全部常数分母整除 2520 = lcm(1..9)"，**在第 8 级失效**。
新的经验规律候选：单个轨道值的分母出现 6048、15120、22680、25920、90720，
其 lcm = **90720 = 2⁵·3⁴·5·7**，而束值分母 3780 | 90720。
