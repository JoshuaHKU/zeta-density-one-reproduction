## 3. 被积对象（Round 132 推导，见 `../phase3/FACET_RECURSION_LOG.md` §4.1）

设 7-圈的边频率 `v_0..v_6`：

```
val({5,2}) = ∫ O₇(walk) · C₅(5-块频率) · C₂(2-块频率) dv
```

* 每个块的连通因子支撑在"块内频率和为零"上 ⟹ 自由维 `7 − 2 = 5`；
* `O₇ = (1 − spread(部分和))₊`；
* `C₂(v) = min(|v|,1) = |v|`（上限恒不绑定，理由同 Phase 0）——
  **作为单项式因子处理，比展成两个重叠因子少一个辅助维**；
* `C₅` 用 F-CYC 展成带符号重叠和，**150 项**（本轮独立确认，与论文 §5.5 一致）。

于是每一项 = 有理多面体上的带符号单项式积分，环境维 **R⁷**（5 自由 + 2 辅助）。

`C₇`：F-CYC 项数 **9366**（已独立确认）。现为 identification grade（`−17/360`）。
**注意**：由单侧性，`C₇` 的一个**可证下界**即可代替精确值——这条路比符号认证
9366 项便宜得多，建议先试。

## 4. 完成：`{5,2}` 的精确值（Round 132，gmpy2 后端）

`run_52.py`，三个放置类逐类精确积分（每类 150 个 F-CYC 项、R⁷）：

| 轨道 | size | 精确值 | 小数 | 代表 | 用时 |
|---|---|---|---|---|---|
| Q0 | 7 | **5/504** | 0.0099206349 | {01234}{56} | 22 s |
| Q1 | 7 | **1/360** | 0.0027777778 | {01235}{46} | 31 s |
| Q2 | 7 | **13/2520** | 0.0051587302 | {01245}{36} | 35 s |

```
{5,2}_total = 7 × (5/504 + 1/360 + 13/2520) = 7 × 45/2520 = 1/8   （精确）
```

**这是一次预注册命中**：候选 `{5,2} = 1/8` 是在跑之前（Round 130，由模型侧
0.124944 的小分母重构）落盘的，符号计算给出的是**恰好 1/8**，偏差 0.00e+00。

于是

```
Σ₇ = {5,2} + C₇ = 1/8 − 17/360 = 7/90 = 0.0777778
m₇ = 685/36 + Σ₇ = 3439/180 = 19.1055556
```

**门 F-SIGMA7**：`Σ₇ ≥ 0.074844` ⟹ **PASS**（余量 3.8%，即 >0.84 所需的
Σ₇ 下界已被满足）。`|Σ₇ − 模型 0.077722| = 5.6e-5 < 3e-3` ⟹ PASS。

> **等级说明（重要）**：`{5,2} = 1/8` 是**精确符号结果**。但
> `Σ₇ = 7/90` 还用到 `C₇ = −17/360`，后者在论文里是 **identification grade**
> （未符号认证）。所以 `Σ₇ = 7/90` 的等级 = `min(精确, C₇ 的等级)`。
> 由单侧性只需 Σ₇ 的**下界**，故只要 `C₇ ≥ −17/360 − 0.0029` 即可，
> 这比符号认证 9366 项便宜得多。
