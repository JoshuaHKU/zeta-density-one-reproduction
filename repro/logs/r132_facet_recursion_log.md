## 步骤 1 — 数学设计（推导）

### 1.1 Lasserre 散度递推

设 `P = {x ∈ R^k : a_i·x ≤ b_i}`，`f` 关于原点齐次、次数 `d`。取向量场
`G(x) = f(x)·x`。则 `div G = ∇f·x + k f = (d + k) f`（Euler）。散度定理给

```
(d + k) ∫_P f = Σ_i ∫_{F_i} f (x·ν_i) dS ,     ν_i = a_i/|a_i|
```

facet 上 `a_i·x = b_i` 故 `x·ν_i = b_i/|a_i|` 为常数：

```
(d + k) ∫_P f = Σ_i (b_i/|a_i|) ∫_{F_i} f dS .
```

### 1.2 消去无理归一化（论文 §5.5 的"投影到坐标超平面"）

把 facet `F_i` 沿坐标 `j` 投影到超平面 `x_j = 0`。投影把 (k−1) 维面积按
`|a_{ij}|/|a_i|` 缩放，故 `dS = (|a_i|/|a_{ij}|) dy`。代入：

```
(d + k) ∫_P f = Σ_i (b_i / |a_{ij}|) ∫_{π_j(F_i)} f(x(y)) dy .
```

**`|a_i|` 精确抵消，全程有理。** 这正是论文所述的安排。

### 1.3 递推的状态与规范化

递推对象是"(多面体, 多项式)"。为了能记忆化，必须给每个面一个**规范键**。

- 面由**紧约束集** `T` 决定：`F_T = P ∩ {a_i·x = b_i, i ∈ T}`。
- 关键观察：**行最简阶梯形的主元列只依赖于行空间**，不依赖消元顺序。
  故 `pivots(T)` 是 `T` 的规范函数；自由列 `free(T) = [n] \ pivots(T)`。
- 且 `span(T∪{i}) ⊃ span(T)` 维数加一 ⟹ `pivots(T∪{i}) = pivots(T) ∪ {j}`，
  其中 `j = min{ f ∈ free(T) : γ_f ≠ 0 }`，`γ` 是 `a_i` 在自由坐标下的约化。
  ⟹ **投影方向 `j` 也由 `T∪{i}` 唯一决定**，递推自洽。

于是记忆化键取 `(T, α)`，`α` 是自由坐标上的单项式指数。

### 1.4 基例与退化面

- `k = 0`：面是一个点 `x_P = d`。可行则 `M = 1`（0 维测度），否则 `0`。
- **空面**：归纳可得 `M = 0`（所有子面为空 ⟹ 基例全 0）。
- **低维但非空的面**（测度 0）：需要它自动为 0。手算两个例子验证：
  - `{x ≤ 0, −x ≤ 0} = {0}`：两个 facet 的前因子都是 `0/1 = 0` ⟹ `M = 0` ✓
  - `{x ≤ 1, −x ≤ −1} = {1}`：前因子 `+1` 与 `−1`，两点都可行 ⟹ 抵消为 `0` ✓

  故**不需要昂贵的隐式等式检测**；相对的两个 facet 的前因子自动反号抵消。

### 1.5 非齐次的处理

代入 facet 方程后单项式变成非齐次多项式。按**全次数分解**成齐次分量，
逐分量套用递推即可（每个分量用自己的 `d`）。

### 1.6 手算校验（写代码前）

`P = [0,1] ⊂ R^1`，约束 `x ≤ 1`（a=1,b=1）与 `−x ≤ 0`（a=−1,b=0）。

- `f = 1`（d=0，k=1）：`1·∫ = (1/1)·M(点 x=1) + (0/1)·M(点 x=0) = 1` ⟹ `∫ = 1` ✓
- `f = x`（d=1，k=1）：`2·∫ = (1/1)·(代入 x=1 得 1) + 0 = 1` ⟹ `∫ = 1/2` ✓

设计通过手算。进入实现。

## 步骤 4 — 应用到未知类

下一步：把 `{2,2,4}`、`{5,2}`、`{6,2}`、`{4,4}` 的被积对象接进来。
这需要在 `walk_integral` 之上再加一层：块大小 ≥ 3 的连通因子要用 F-CYC
展开成带符号的重叠和（`C₄` 26 项、`C₅` 150 项、`C₆` 1082 项），每一项多一个
重叠变量。接口已在 `facet_recursion.walk_integral(pos, extra_walks=…)` 里预留。

### 4.1 一般类被积对象的推导（已完成）

把 Phase 0 的形式推广到任意块分拆。设 k-圈的**边**频率 `v_0..v_{k-1}`：

* 每个块带一个连通因子 `C_{b_j}`，它支撑在"块频率和为零"上 ⟹
  自由维数 `Σ_j (b_j − 1) = k − r`；
* 圈本身带走位重叠 `O_k = (1 − spread(部分和))₊`；
* **`val = ∫ O_k · Π_j C_{b_j} dv`**。

F-CYC 把连通因子展成带符号重叠和：
`C_b = Σ_{P⊢块} (−1)^{|P|−1} Σ_{循环序} ov(0, w_{σ1}, w_{σ1}+w_{σ2}, …)`，
`w_p = 块内频率和`。b=2 处两个分拆给 `1 − (1−|v|)₊ = min(|v|,1)` ✓。

**一个省维数的观察**：每个边频率都是两个走位之差，故 `|v| ≤ spread < 1`，
`min(|·|,1)` 的上限恒不绑定 ⟹ **size-2 块可以直接当单项式因子 `|v|`**，
比展成两个重叠因子少一个辅助维。size ≥ 3 的块才用 F-CYC 展开。

于是每一项 = `(符号积) × ∫ (若干重叠之积) × (单项式) dv`
= 有理多面体上的带符号单项式积分，每个重叠因子加一个辅助变量——
正是 `facet_recursion.py` 的输入形状。代码：`class_integral.py`。

### 4.3 算力性质判定（回答"要不要 GPU"）

**不要 GPU。** 这个负载与 GPU 的适用面正交：

| 本负载的特征 | GPU 的适用面 |
|---|---|
| 任意精度**有理数**（Python `Fraction`/大整数） | 稠密低精度**浮点** |
| 面格上的**不规则递归**、数据相关分支 | 规则 SIMD、无分支 |
| **哈希记忆化**（共享可变状态，且是主要加速来源） | 无共享状态的流式并行 |

在 GPU 上做任意精度有理算术需要自己实现 bignum 内核，对这里的操作数规模
通常**比 CPU 更慢**；而 warp divergence 会摧毁占用率；记忆化表更是敌对结构。

**真正需要的是三样**（按性价比排序）：

1. **算法**（最高杠杆，先做）：
   (a) **跨项共享记忆化**——同一个类的所有 F-CYC 项共享 `O_k` 那一组约束，
       现在每项都新建 `Polytope` 从零开始，白扔了绝大部分面格；
   (b) **对称约化**——`v → −v` 与块内置换；
   (c) **退化项剪枝**——先廉价判定走位退化的项，直接判 0。
   预期合计 10² 量级。
2. **算术后端**：`gmpy2` 替换 `Fraction`（大整数运算通常 3–10×），或 PyPy。
3. **CPU 核数 + 墙钟**：F-CYC 项之间是**完全独立**的，线性扩展。
   多核机器（32–128 核）+ 数小时到数天，而不是 GPU。

在做完 1 之前不建议投任何硬件——现在的瓶颈是每项从零重建面格，不是算力。

## 步骤 5 —— 两条优化方向，**双双被实测否掉**（Round 132）

### 5.0 前提更正

Round 132 早先记的"C₅ 跑 10 分钟未结束 ⟹ 单项成本主导"**是错的**：那次输出被
`| head` 的管道缓冲挡住，卡住的是排在后面的 `{6}`（1082 项）。真实成本：

```
C₅ 的一个典型项：R^6、去重后 14 条约束、0.6 s、面格 330 节点、
                 维数判定 314 次（其中 30% 判退化）
C₅ 全类（150 项，8 核）：40 s
```

主导项是**项数 × 维数**，不是"每项天价"。定标表已据此更正。

### 5.1 跨项归并（原计划 1(a)）—— **零收益，否掉**

设想：`ov` 只依赖位置的**集合**（`spread = max − min`），故不同 F-CYC 项若给出
同一位置集合即可合并，符号还可能抵消。实测：

| 类 | 项数 | 不同位置集合 | 非零符号组 |
|---|---|---|---|
| `C₅` | 150 | **150** | 150 |
| `{4,2}` | 26 | **26** | 26 |
| `{6}` | 1082 | **1082** | 1082 |
| `{5,2}` | 150 | **150** | 150 |

**零合并、零抵消。** 否掉。

### 5.2 降维：用元胞分解换掉辅助变量（方向 1）—— **1.3–2.2× 更慢，否掉**

每个重叠因子现在花一个辅助变量 `t`（约束 `t ≤ p ≤ t+1`）。替代方案是**元胞分解**：
在 `argmax(W)=i、argmin(W)=j` 的元胞上

```
ov(W) = 1 − (p_i − p_j)        （一次多项式）
元胞约束： p_i ≥ p_k ∀k,  p_j ≤ p_k ∀k,  p_i − p_j ≤ 1
```

交易是 **−1 维 × |W|(|W|−1) 个元胞**。对 `C₅` 的循环走位：25 个元胞（且该走位
被全部 150 项共享，元胞只需枚举一次）。实测（`dimreduce.py`，两式**结果逐项相等**，
故是公平比较）：

| 项 | 辅助变量式 | 元胞式 | 比 |
|---|---|---|---|
| term 0 (R⁵→R⁴) | 0.09 s | 0.20 s | 2.2× 慢 |
| term 5 (R⁶→R⁵) | 1.04 s | 1.75 s | 1.7× 慢 |
| term 40 | 1.66 s | 2.11 s | 1.3× 慢 |
| term 100 | 1.62 s | 2.63 s | 1.6× 慢 |

**降一维省下的，抵不过 25 个元胞。** 否掉。

### 5.3 顶层冗余剔除（方向 2）—— **移除 0 条约束，纯开销，否掉**

理论上成立：全局冗余的半空间包含 `P`，故包含 `P` 的每个面，只能在低维（零测度）
面上取紧 ⟹ 可以一次性删掉，整棵子树随之消失。实现为 `Polytope._prune()`
（对每条约束 `i` 判 `{i}` 面是否满维）。实测：

```
term 40 的多面体：去重后 18 条约束 → 冗余剔除后 18 条 → 移除 0 条
四项合计 4.82 s vs 4.41 s  →  0.91×（更慢）
```

**走位多面体在去重之后已经是无冗余描述**，所以这条只是白付 18 次 LP。
`_prune()` 保留但**默认不调用**（其他约束族可能受益）。

### 5.4 本步骤的净结论

三条候选优化全部被实测否掉。这不是失败，是把搜索空间收窄了：

- 面格规模不是被冗余约束撑大的（5.3）；
- 也不是被重复项撑大的（5.1）；
- 维数与元胞数之间的交易在这个尺度上是**负的**（5.2）。

剩下的杠杆只有两类，都不涉及算法结构：
1. **算术后端**：`gmpy2` 替 `Fraction`（大整数 3–10×）或 PyPy；
2. **核数 × 墙钟**：F-CYC 项之间完全独立，线性扩展。

**GPU 依然无用**（任意精度有理数 + 不规则递归 + 哈希记忆化）。
