## 4. 一项主动上报：A1 前置门失败，Σ₁₁..Σ₁₄ 暂不可用

与 r146 无关，但与 §4 排产的第 2 项直接相关，一并报此。

A1（N=128，10⁷ 样本，238，2178 s）统计精度达标

**但方案规定的前置门"已知矩 ≤0.5 sd 复现"失败**：

| j | Σⱼ 实测 | ± | 对精确值偏差 |
|---|---|---|---|

**六个偏差全部为负**，非随机涨落。诊断证据：

    Sigma_2 偏差 @ 20 万样本  = -2.73e-05
    Sigma_2 偏差 @ 1000 万样本 = -2.70e-05      样本量差 50 倍，偏差一致到 1%

**偏差与样本量无关 ⟹ 是 N=128 的有限维系统项**，一直存在；
20 万样本时被 ±6.2e-5 的统计误差盖住（当时报 −0.4 sd），
样本量 ×50 后标准误降到 8.8e-6，偏差显形。
**精度提高不是把误差变小，而是把偏差变可见——这道前置门工作正常。**

**已采取的措施**：238 上排了 N=192、N=256 各 10⁷ 样本（约 2 h + 4.8 h），
做三点 1/N² 标度检验与外推。**取三点而非两点**：两点只能假定 1/N² 律，

落在线上，则外推截距为 N→∞ 真值，且偏差本身成为可入册常数；

**在此之前 Σ₁₁..Σ₁₄ 不可用于 k=14 定价**——它们携带同一系统偏差，

## 6. 追加（N=192 落地）：三点 1/N² 检验**在 10⁷ 样本下无法判定**

N=192、10⁷ 样本、6077 s。与 N=128 对比六个已知矩的偏差：

| j | 偏差@N=128 | 偏差@N=192 | 比值 | 1/N² 预言 0.444 |
|---|---|---|---|---|
| 2 | −2.70e−05 | −8.10e−06 | 0.300 | |
| 4 | −4.29e−05 | −1.12e−05 | 0.261 | |
| 5 | −7.98e−06 | **+2.90e−06** | **−0.364** | 变号 |
| 6 | −6.62e−05 | −2.19e−05 | 0.331 | |
| 7 | −2.94e−05 | −1.52e−05 | 0.517 | |
| 8 | −1.09e−04 | −6.68e−05 | 0.612 | |

**不要读作"1/N² 被证伪"。** 比值散布在 −0.36 到 +0.61，但**分子已经掉进
噪声里**：N=192 下 Σ₂ 的偏差 −8.1e−6 对应约 0.9 sd，Σ₅ 的 +2.9e−6 更是
纯噪声。比值的散布与噪声完全相容，**这组数据不足以区分 1/N²、1/N 或别的律**。

**能确定的只有一件事**：偏差确实随 N 缩小——已知矩的偏差从 N=128 的
**−3.1…−3.5 sd** 降到 N=192 的**约 1 sd**。方向对，幅度不可辨。

Σ₉..Σ₁₄ 的位移同样处在边缘：

    Sigma_11  -2.55e-04 (sd 2.9e-04)    Sigma_13  -1.49e-03 (sd 1.1e-03)
    Sigma_12  -5.93e-04 (sd 5.5e-04)    Sigma_14  -3.35e-03 (sd 2.2e-03)

**均为 0.9–1.5 sd，皆未分辨。**

### 6.1 由此得出的方案缺陷（重要）

**三点检验按当前设计不可能成功。** N=256 正在跑，但按同一逻辑，
它的残余偏差只会更小（预期 ~0.5 sd），**更不可辨**。加第三个 N 点
并不能救这个检验——**问题不在点数，在每点的精度**。

要在 3 sd 上分辨 N=192 处约 1e−5 的偏差，需 sd ≈ 3e−6，
即样本量再 ×9 → **10⁸ 样本**（N=128 约 6 h，N=192 约 17 h）。

### 6.2 三个可选方向，请数学侧裁决

**(a) 加样本**：N=128 与 N=192 各跑 10⁸ 样本（约 23 h，238 独占）。
能真正判定标度律，代价最大。

**(b) 接受并如实标注系统带**：已知矩在 N=128 的偏差不超过 1.1e−4，
可将其作为 Σ₉..Σ₁₄ 的**系统不确定度**与统计误差并列申报。
k=14 定价随之带一条系统带。零额外成本，但常数等级下调。

**(c) 用已知矩标定偏差模型**：j ≤ 8 有六个精确值，可拟合 bias(j, N)
再外推到 j = 9..14。比 (b) 精细，但要先在 (a) 的精度上确认模型形状，
否则是拿一个未验证的模型去修正——**这正是今天已经栽过的那类错**。

**我的建议是 (b) 先行、(a) 排队**：(b) 让 k=14 带级结论立刻可交付且
分级诚实；(a) 在 C₉ 完工、机器空出后再做，用于日后升级。
**但这是分级判断，应由数学侧定。**

N=256 已在跑（约 4.8 h），不中止——它对 (c) 的模型形状仍有参考价值，
且成本已经付出。
