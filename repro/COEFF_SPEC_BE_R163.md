## 2. 正确公式（簇展开，行列式过程标准机器）

    m_b(N)·N^{b+1} = Σ_{m⃗∈[0,N)^b} Σ_{P⊢[b]} ∏_{B∈P} κ_B ,
    k_i = m_i − m_{i+1 mod b}

每块的真累积量 κ_B 的**箱表示**：

    κ_B = δ[Σ_{i∈B} k_i = 0] ·
          Σ_{Q ⊢ B}  (−1)^{|Q|−1}
          Σ_{σ = Q 的类上的循环序}  (N − span_σ(g))₊

其中：
- **Q（合并分拆）**：把块 B 的槽位合并成类；类 C 的合并频率
  g_C = Σ_{i∈C} k_i；
- **σ**：Q 的**类**上的循环序，共 (|Q|−1)! 个（固定一个类为
  起点、排列其余即可）；
- **span_σ(g)**：沿 σ 的（合并）部分和序列的 max − min。
  闭合走（Σg = 0）下与起点选择无关——这是循环序（而非线性
  序）足够的原因；
- **系数 = ∏_B (−1)^{|Q_B|−1}，纯符号，无阶乘因子**。

来源：ρ^T_m = (−1)^{m−1} Σ_{循环置换} ∏K（行列式过程簇函数
的循环结构）+ 线性统计的对角合并层（同点分拆 Q）。你们的
槽位级 T_{P,σ}（无合并）只覆盖 Q = 全单点类的子族；合并项
的箱用**类边界**部分和，数值上不等于任何无合并箱。

## 3. 每块因子的自检值（先记，实现后必须逐位命中）

- |B|=1：κ = N·δ_{k=0}；
- |B|=2, k≠0：κ = N − (N−|k|)₊ = min(|k|,N)（合并项 +N、
  未合并项 −(N−|k|)₊）；k=0：κ = 0（两项相消）；
- 块因子按类数分层：q(s) = Σ_m S(s,m)(m−1)! =
  1, 2, 6, 26, 150（s = 1..5）；Σ_P ∏ q(|B|) = Fubini(b)。
