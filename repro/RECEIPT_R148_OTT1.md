## 2. 实现独立性（指令书硬性要求）

`repro/engines/tt_moments.py`，从零编写，**未复用数学侧任何脚本**。
仅依据 `r147/p3_round1_verdict.md` §1 的数学规格。三层：

1. **Murnaghan–Nakayama 特征标**：β-数（首列钩长）编码，去掉一条长度 r
   的边缘带 = 把一个 β 值下移 r 到空位，符号 `(−1)^(跨过的 β 个数)`；
   `functools.lru_cache` 记忆化。
2. **Schur 正交主公式**：`E[p_μ p̄_ν] = Σ_{λ⊢K, ℓ(λ)≤N} χ^λ(μ)χ^λ(ν)`。
3. **多重集聚合 + span-DP**：期望只依赖 (μ,ν)，span 权重只依赖步序，
   两者解耦。`(N−span)₊ = #{t : 走位 ⊆ [t, t+N−1]}`，逐窗口用
   (已用多重集, 当前位置) 状态 DP 计数。

## 4. 途中两个缺陷（均为本侧，已修并在代码中注释）

span-DP 的窗口偏移枚举范围错了两次：

1. 初版按 `sum_neg` 截断，漏掉下探较深的窗口
   —— `span_weight([2,−2],3)` 给 1，应为 2；
2. 改窄后又漏掉上方窗口
   —— `span_weight([1,−1],3)` 给 3，应为 4。

正确范围：`lo ∈ [sum_neg − (N−1), 0]` 且 `hi ≥ 0`。

**两次都是被 §3.3 的低阶核对抓住的，不是被靶抓住的。**
先建立可核对的低阶基准、再上预注册靶——这个次序是本次没有翻车的原因。
若直接上 m₉(7)，两个 bug 都会表现为"不命中"，而无从定位。
